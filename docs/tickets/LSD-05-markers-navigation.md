# LSD-05 - Markers & navigation

## Scope

- Drop marker at playhead.
- Jump to next / previous marker.
- Set punch-in / punch-out (and toggle autopunch).
- Nudge/jump by bar.

## Notes

- MCU covers marker prev/next and drop via function-key layers; anything MCU can't reach cleanly falls back to the LSD-06 keystroke path once it exists.

## Done when
